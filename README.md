# finarchive-policies

The privacy policy and terms of use for **FinArchive**, a personal application
used by its author to read their own bank accounts.

FinArchive is not a product and not a service. It has one user, who is also its
author and the only person whose data it touches. These documents exist because
an open-banking provider asks any registered application to publish them, and
publishing something accurate seemed better than publishing nothing.

- [PRIVACY.md](PRIVACY.md) — what data is processed, by whom, and where it goes
- [TERMS.md](TERMS.md) — the terms under which the application is used

**This repository contains policy documents and nothing else.** No code, no
configuration, no data. That is deliberate: it is the only public repository
here, so it is kept to material that is safe to read and uninteresting to steal.
